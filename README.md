# 360° 파노라마 뷰어

브라우저에서 바로 동작하는 간단한 360° 파노라마 이미지 뷰어입니다. 외부 의존성 없이 `index.html` 한 파일로 완성되어 GitHub Pages에서 정적 호스팅이 가능합니다.

## 사용법

### 1. 이미지 업로드
- **equirectangular 2:1 비율 이미지** (예: 4096×2048, 6000×3000)를 준비합니다.
- 화면 중앙의 업로드 영역을 클릭하거나, 파일을 드래그 앤 드롭합니다.
- 지원 포맷: `JPG`, `PNG`, `WebP` 등 브라우저가 해석 가능한 이미지 포맷.
- **여러 장을 한 번에** 선택(또는 드롭)하면 전자책처럼 한 장씩 넘겨볼 수 있습니다.

### 2. 시점 조작
| 동작 | 방법 |
| --- | --- |
| **시점 회전 (좌우/상하)** | 마우스 드래그 |
| **줌 인/아웃** | 마우스 휠 스크롤 |
| **시점 높이(Pitch) 조절** | 우측 세로 슬라이더, 또는 `↑` / `↓` 키 |
| **다음 / 이전 이미지 (페이지 넘기기)** | 화면 오른쪽 / 왼쪽 가장자리에서 안쪽으로 스와이프, 또는 `→` / `←` 키 |
| **전체화면 토글** | 우측 하단 전체화면 버튼 |
| **자동 회전 시작/정지** | 우측 하단 자동 회전 버튼 |

### 3. 기능 상세
- **전체화면**: 버튼 클릭 시 브라우저 전체화면 모드로 전환됩니다. 다시 누르거나 `ESC` 키로 종료.
- **자동 회전**: 일정한 속도로 좌우 시점이 회전합니다. 드래그 시 자동 회전은 일시 중지됩니다.
- **페이지 넘기기**: 여러 장을 올렸을 때, 화면 좌우 가장자리(폭의 약 15%)에서 시작한 가로 스와이프는 전자책처럼 종이가 넘어가는 애니메이션으로 다음/이전 이미지로 전환됩니다. 종이가 손가락을 따라오며, 절반 이상 끌거나 빠르게 튕기면 넘어가고 아니면 제자리로 돌아옵니다. 화면 가운데에서 시작한 드래그는 기존처럼 시점 회전입니다. 하단에 `현재 / 전체` 페이지가 표시됩니다.
  - iOS Safari는 화면 맨 끝에서의 스와이프를 '뒤로 가기'로 쓰므로, 끝에서 살짝 안쪽에서 시작하는 것이 좋습니다.
- **Pitch 슬라이더**: 카메라가 바라보는 수직 각도(위/아래 기울기)를 조절합니다. 키보드 `↑` `↓`로도 미세 조정 가능.

## 로컬에서 실행하기
저장소를 clone 한 뒤 `index.html`을 브라우저에서 바로 열면 됩니다.

```bash
git clone https://github.com/thehanfilm-code/panorama-viewer.git
cd panorama-viewer
# Windows
start index.html
# macOS
open index.html
```

## 배포
이 저장소는 GitHub Pages로 호스팅됩니다. `main` 브랜치의 루트가 자동으로 배포됩니다.

## 요구 이미지 규격
- **비율**: 2:1 (equirectangular projection)
- **권장 해상도**: 4096×2048 이상
- **용량**: 브라우저 메모리 제약으로 20MB 이하 권장

## AR 벽걸이 데모 (`/ar`)
작품을 실제 치수의 캔버스 3D 모델(GLB)로 만들어, 폰 브라우저에서 AR로 벽에 걸어 볼 수 있는 페이지입니다. 앱 설치 없이 동작합니다.

- `ar/index.html` — Google `<model-viewer>` 기반. Android(Scene Viewer), iPhone(AR Quick Look) 지원. 데스크톱에서는 3D 미리보기만.
- 3D 모델(GLB)은 `ar/img/*.jpg`와 페이지 안 `WORKS`의 치수(cm)로 브라우저에서 즉석 생성됩니다. 작품을 추가하려면 이미지와 `WORKS` 한 줄만 더하면 됩니다.
- 카메라 권한이 필요하므로 **실제 사이트 주소(GitHub Pages)에서 열어야** AR 버튼이 동작합니다. iframe 안이나 `file://`로는 3D 미리보기만 됩니다.
